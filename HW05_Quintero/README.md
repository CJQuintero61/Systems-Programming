# README
This program is to learn more about using signals for process
    communication. Communication is only to be done through
    signals and no other means.

### To run:
    make all
    ./program1 & ./program2 & ./program3    # to run all 3 programs at once
    make clean

### Message.txt
This holds the phrase "Hello World" in binary to be used by Program1 to execute
the flow of the assignment
